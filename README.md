# Student Record Management System (SRMS)

A full-stack web-based Student Record Management System built using:

- Flask (Python)
- SQLite (DBMS)
- C Shared Library (DSA via ctypes)
- HTML, CSS (Web UI)

## Features
- Role-based authentication (Admin / Teacher / Student)
- Student record management (CRUD)
- High-performance sorting, searching, and statistics using C
- Export reports to PDF and Excel
- Data visualization (charts)
- Sample dataset for quick demo

## Technologies Used
- Operating Systems: Shared libraries, process-level integration
- DBMS: SQLite
- DSA: Sorting, searching, statistics in C
- Web: Flask, HTML, CSS
